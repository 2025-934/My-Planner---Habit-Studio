# My-Planner---Habit-Studio
# 🌸 My Monthly Planner & Habit Tracker

A stunning, aesthetic, and fully interactive **Monthly Habit Tracker and Daily Task Management** web application designed with a soft pastel productivity theme. Inspired by popular aesthetic digital planners and spreadsheet habit trackers, this project helps you cultivate consistent routines, track daily progress, and stay motivated effortlessly.

---

## ✨ Key Features & Highlights

- **📅 Interactive Monthly Habit Grid:** A comprehensive tracker layout mapping tasks vertically across all days of the month with independent checkboxes and category groupings.
- **📊 Dynamic Analytics & Charts:** Integrated **Chart.js** graphs displaying daily completion rates, weekly consistency breakdown, category distributions, and a calendar heatmap.
- **📋 Daily Task View:** Dedicated daily checklist view showing active tasks, completion status meters, and real-time progress calculations for any selected date.
- **🏷️ Customizable Categories:** Pre-loaded with default categories (*Academics, Hobbies, Health & Fitness, Personal Growth, Skills & Career*) with full CRUD support to add, rename, or delete categories and tasks.
- **🎨 Aesthetic Pastel UI/UX:** Crafted with soft lavender, baby pink, mint green, and peach accents, rounded cards, subtle shadows, and a clean glassmorphism layout.
- **💾 Local Storage Persistence:** Automatically saves all task data, categories, and checkboxes in your browser so your records stay safe across sessions.
- **📥 Data Export & Reset:** Easily export your monthly tracking log as a CSV file or reset data whenever needed.

---

## 🚀 Technologies Used

- **HTML5** (Semantic structure)
- **Tailwind CSS** (Modern utility styling & responsive layouts)
- **JavaScript (ES6+)** (State management, date calculations, and Local Storage API)
- **Chart.js** (Dynamic data visualization and interactive graphs)
- **FontAwesome** (Clean minimalist iconography)
